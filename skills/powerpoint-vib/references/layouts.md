# VIB-CCB template — full slide layout inventory

Generated by `scripts/list_layouts.py assets/vib-ccb-template.pptx`. Re-run that script any time the
template is updated to regenerate this file.

**Why this file exists:** `Presentation.slide_layouts` in python-pptx only exposes the layouts that
belong to the presentation's *first* slide master. This template has **5 slide masters** and **137
layouts total** — 133 of them are invisible unless you iterate `prs.slide_masters` yourself. This file
is the full list so you can pick a layout by name without guessing, and the indices below map directly
to how you'd fetch each one in code:

```python
layout = prs.slide_masters[MASTER_INDEX].slide_layouts[LAYOUT_INDEX]
```

## Table of contents

| Master index | Layout count | What's in it |
|---|---|---|
| [0](#master-0-4-layouts) | 4 | Title slides (Light 01/02, Dark 01/02) |
| [1](#master-1-57-layouts) | 57 | Content layouts, set A (columns, images, timelines, highlights, one-column variants) |
| [2](#master-2-58-layouts) | 58 | Content layouts, set B — same names as master 1, plus one extra (`1_Full widt image`) |
| [3](#master-3-14-layouts) | 14 | Generic/default PowerPoint layout names (Section Header, Two Content, Comparison, Blank, etc.) |
| [4](#master-4-4-layouts) | 4 | End slides (Light 01/02, Dark 01/02, plus a `1_End Slide - Light 02` variant) |

Masters 1 and 2 have near-identical layout *names* but are separate masters (separate themes/masters
in the OOXML package) — if in doubt which one matches the deck's intended look, check
the original example slides (not bundled — generate them locally with `scripts/potx_to_pptx.py <potx> --reference-out "$TMPDIR/vib-ccb-reference.pptx"`, or open the `.potx` in PowerPoint) and see which master the example slides actually use for that layout name, rather than
assuming. The brand's own examples only use masters 0, 1 and 4.
