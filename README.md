# BioIT & AI Skills

A shared library of agent skills for bioinformatics work at VIB-CCB BioIT. A skill is a folder with a `SKILL.md` file that tells an AI agent how to do one task well, for example annotating cell types or reviewing a pathway analysis.

- **Use a skill:** open its folder, read `SKILL.md`, and copy the folder into your agent's skills directory.
- **Add a skill:** see [CONTRIBUTING.md](CONTRIBUTING.md). It takes a copy of the template and a pull request.
- **Machine-readable list:** [`skills.json`](skills.json).
